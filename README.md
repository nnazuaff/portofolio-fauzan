# Fauzan Portfolio

## Menjalankan lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000` di browser.

Untuk metadata Open Graph saat deploy, salin `.env.example` menjadi `.env.local`
dan ganti `NEXT_PUBLIC_SITE_URL` dengan domain produksi.

## Perintah lain

```bash
npm run build
npm run start
```
